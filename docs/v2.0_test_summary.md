## Phase 3: FIELD++ Part 1 (Multi-Dimensional Distance) ✅

**Formula estesa:**
```
v0.1: d² = dx² + dy²
v2.0: d² = (dx/σx)² + (dy/σy)² + (df/σf)² + (dh/σh)² + (dc/σc)²
```

**Dimensioni aggiunte:**
- **df:** font affinity (0=same, 1=different)
- **dh:** hierarchy affinity (0=same span, 0.5=same line, 0.8=same block, 1=different)
- **dc:** color affinity (0=same, 1=different)

**Implementazione:**
- `_phi()` esteso con sigma_font, sigma_hierarchy, sigma_color
- `extract_page()` accetta sigma parametri (default 0 = disabled)
- Backward compatibility: sigma=0 → v0.1 identico

**Test con sigma sperimentali (font=50, hierarchy=30, color=100):**
- Daikin p.21: 102 mapped (v0.1) → 102 mapped (v2.0) — no change
- **Atteso:** pagina già 100% accurate, no room for improvement
